# Agent Note: Turn-process folding follows loaded window coverage

Status: implemented

[English](2026-09-21-turn-process-window-coverage.md) | 中文

## Problem

折叠一个已结束轮次的过程行，需要该轮次的三个事实：过程范围从哪开始、最终答案边界在哪里，以及摘要要报告多少工具调用、回复与委派。Chat 投影只能从已加载的事件窗口推导这三个事实，因此既有规则在窗口仍不完整时拒绝折叠任何轮次：窗口头部那个最早的已加载轮次可能被截断，它的范围和计数就会出错。当时手边唯一表示"完整性"的信号是会话级的 `hasMore`，于是它拦住了所有轮次，而不是仅仅拦住真正被截断的那一个；而每点一次「加载更早」，也只是把更早的轮次装进来，并不会让眼前这些轮次变得可折叠。

会话按每次 50 条 user/assistant 消息分页，于是一个又长又重工具调用的轮次就能占掉大半页。对于一个平均每轮占满一页的 61 轮会话，读者打开时看不到任何折叠——整个转录（含过程行）全量铺开，直到手动把每一页都加载完。原始决策及其接受的代价见 [Web 轮次过程折叠笔记](../../archived/feature/2026-08-14-web-turn-process-folding.md)。

## Decision

`ChatTurnProcessPresentation` 新增 `turnStartLoaded`，由 `ChatTurnProcessProjector` 从轮次 Location 上记录的 `turn/start` 事件推导。已加载的窗口是会话日志的连续后缀，因此只要 `turn/start` 已加载，就证明该轮次的全部事件都已加载；没有它则说明该轮次被窗口头部截断，只有这种轮次仍然不予折叠。`ChatNodeSeat` 在 `turnStartLoaded` 为真时折叠已关闭轮次，否则仅在历史全部加载完成后才折叠——这为完全不记录 `turn/start` 的日志保留了原有回退路径。

窗口头部轮次保留原有保证：在「加载更早」补齐它的 `turn/start` 之前绝不折叠，因此折叠永远不会隐藏读者无法加载回来的过程行。过程范围、答案边界与摘要计数仍然由投影和 `TurnProcessSpec` 负责；本次改动只改变哪些轮次具备折叠资格。

于是每次翻页都可能把它补齐的那个轮次收起来，频率从"每个会话一次"变成"每次翻页一次"。稳定 Seat、焦点守卫与手动展开存储的行为不变，因此读者可以重新展开正在看的那一组，且该选择在页面生命周期内的视图重挂载后依然保留。

## Alternatives considered

**保留会话级的 `hasMore` 闸门。** 否决：它连窗口已完整覆盖的轮次也一并拒绝折叠，而代价随会话长度增长——恰恰是折叠最有价值的地方。

**先加载完整历史，再折叠。** 否决：结果与手动翻页相同，却要在打开会话时就把长会话的全部事件拉进浏览器并重放一遍。

**在 Seat 里从 `routedNode.location` 计算完整性。** 否决：跨节点轮次事实已由投影持有并重新发布给受影响轮次中的每个 Seat；让 Seat 自己再算一遍，等于把必须对整轮所有行保持一致的规则复制成两份。

**用客户端插件放宽闸门。** 否决：该判定与成员隐藏步骤都在 Chat 目标自己的 Seat 内部，而客户端扩展点只能增设 slot、服务与节点种类，插件要么替换整个对话视图，要么隐藏并非它拥有的行。

**只折叠当前翻页之前就已经完整的轮次。** 否决：这需要"刚刚变完整"的瞬时记账，而且恰好把某个轮次的折叠推迟到证明它完整的那一次翻页之后——正是读者正在看的那个轮次。

## Consequences

长会话在打开时就会折叠窗口覆盖到的每个已关闭轮次，之后每次「加载更早」都会折叠它补齐的轮次；只有窗口头部轮次继续等待，而那个轮次通常本就处于运行中或已中断。摘要计数保持精确，因为可折叠的轮次在构造上就是完整加载的。

代价是翻页期间的重排：一次翻页可能收起读者正锚定的那一组，而旧规则把这一切都推迟到历史完成的那一瞬间。滚动锚定与焦点守卫不变，手动展开也会让重新打开的分组保持展开。

## Testing

`chat-view.client.spec.tsx` 钉住 Seat 的四种情况：被窗口头部截断的轮次在更早历史仍在时保持展开；窗口已完整覆盖的已关闭轮次立即折叠；没有记录 `turn/start` 的轮次依赖历史完成这一回退路径折叠；以及某次加载补齐 `turn/start` 后该轮次随即折叠——包括其后的手动展开。`conversation-node-definitions.client.spec.ts` 钉住让第四种情况无需重载即可生效的投影刷新：prepend 记录该轮次 `turn/start` 的那一页，会让保留下来的过程 source 上 `turnStartLoaded` 翻转。浏览器分页场景 `chat-scroll-contract.e2e.ts` 断言「加载更早」仍在时已经出现折叠控件。
